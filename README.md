#Characterizing Mechanistic Uniqueness and Identifiability Through Circuit Analysis

This is the accompanying code to the paper Characterizing Mechanistic Uniqueness and Identifiability Through Circuit Analysis

Each of the experiments discussed in the paper has a corresponding notebook file in the google drive.

The circuit enumeration procedure we used in our code was largely derived from the codebase of Everything, Everywhere, All at Once: Is Mechanistic Interpretability Identifiable?.
