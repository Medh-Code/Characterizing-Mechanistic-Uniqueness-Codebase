**Characterizing Mechanistic Uniqueness and Identifiability Through Circuit Analysis**

This is the accompanying code to the paper Characterizing Mechanistic Uniqueness and Identifiability Through Circuit Analysis

Each of the experiments discussed in the paper has a corresponding notebook file in the google drive.

The circuit enumeration procedure we used in our code was largely derived from the codebase of the paper, Everything, Everywhere, All at Once: Is Mechanistic Interpretability Identifiable?. The paper is available here [Paper](https://arxiv.org/abs/2502.20914) and the corresponding codebase can be found here [Github](https://github.com/ArthurConmy/Automatic-Circuit-Discovery/blob/main/README.md).
